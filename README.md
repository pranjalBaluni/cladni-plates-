# Pluggable Audio Player Web Application

A sleek, responsive audio player designed with a modern dark theme using Tailwind CSS and native HTML5 Audio APIs. This version supports dynamically adding audio files right from your browser.

## Features
- **Upload Any Audio:** Click the `+` icon in the Library sidebar to select and play local `.mp3`, `.wav`, or `.m4a` files instantly. No server required; everything runs locally in your browser.
- **Responsive Layout:** Works beautifully on desktop and mobile.
- **Native Audio Integration:** Uses HTML5 `<audio>` routing directly to default system speakers.
- **Media Controls:** Play, pause, skip backward, skip forward, and interactive progress scrubber.
- **Ready-to-Use UI:** Built with Tailwind CSS and FontAwesome for crisp typography and iconography.

## Running Locally

1. Download or clone this repository.
2. Open `index.html` in any modern web browser (Chrome, Firefox, Safari, Edge).
3. The player will load a few dummy royalty-free tracks by default. Use the `+` button in the UI to add your own files on the fly.
